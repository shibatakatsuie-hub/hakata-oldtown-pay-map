# 博多旧市街PAY 加盟店マップ（非公式）

博多旧市街PAYの利用可能店舗を、スマホの地図で探せる静的サイトです。
サーバ不要（HTML + JavaScript + Leaflet + JSON）で、Cloudflare Pages の無料枠で動かせます。

> 本サイトは非公式の加盟店検索サービスです。発行者（御供所名店会）・運営事務局とは関係がありません。

## できること

- 店名・住所の検索、カテゴリ（飲食・宿泊・小売…）とコンビニの絞り込み
- 現在地から近い順の並び替え、500m / 1km / 2km 以内の絞り込み
- 店ごとの「Googleマップ」ボタン（店名＋住所で検索 → 営業時間・口コミ・写真を Google 側で確認）
- 「本店のみ利用可」「夜限定」などの利用条件メモの表示
- 非公式の明示・出典・取得日の表示

営業時間と店舗画像は、**データを入れた店だけ**表示されます（入れていない店は従来どおり Googleマップ遷移のみ）。入れ方と注意点は下の「営業時間・店舗画像を入れる」を参照してください。
Google の営業時間・写真を取得して保存することは、Google の規約上できないため行いません。

## 構成

```
public/                  ← これをそのまま公開（Cloudflare Pages の出力ディレクトリ）
  index.html app.js style.css lib.js _headers
  data/index.json        ← 地域（プログラム）の一覧と出典情報。build_data.py が生成
  data/hakata-oldtown-pay.json   ← 店舗データ。build_data.py が生成
raw/hakata-oldtown-pay.csv       ← 店舗データの元（人とAIが編集する唯一のソース）
config/programs.json             ← 出典URL・利用期間・地図の初期位置など
config/manual-coords.json        ← 座標の手動上書き  {"<店舗id>": {"lat": 33.59, "lon": 130.41}}
cache/geocode-cache.json         ← 住所→座標のキャッシュ（geocode.py が生成）
scripts/                         ← build_data.py / geocode.py / common.py
tests/lib.test.js                ← 絞り込み・距離計算のテスト
CLAUDE.md, .claude/commands/     ← Claude Code 用の更新手順
```

## はじめかた（ローカル）

```bash
# 1. 住所 → 緯度経度（国土地理院の住所検索API。初回のみ。約76〜150秒）
python3 scripts/geocode.py

# 2. JSON を生成・検証
python3 scripts/build_data.py            # 公開前は --strict を付ける（座標漏れもエラーにする）

# 3. 確認
python3 -m http.server -d public 8000    # http://localhost:8000
node tests/lib.test.js
```

**初期状態では店舗に座標が入っていません**（作成環境から住所検索APIに接続できなかったため）。
手順 1 を実行するまで、地図にピンは出ず、一覧と Google マップ遷移だけが動きます。
住所の精度は街区（番地）レベルに丸められる場合があります。ずれが目立つ店は `config/manual-coords.json` で上書きしてください。

## Cloudflare Pages へ公開

1. GitHub にこのフォルダを push する
2. Cloudflare Pages で「Git を接続」→ リポジトリを選択
3. ビルドコマンド: なし（空欄） / ビルド出力ディレクトリ: `public`
4. 以降は push するたびに自動デプロイ

無料プランはビルド回数が月500回までなので、データ更新はまとめて push するのがおすすめです。

## データ更新の流れ

```
公式サイトの「利用可能店舗」→ raw/hakata-oldtown-pay.csv を更新
 → python3 scripts/geocode.py（新しい住所だけ問い合わせ）
 → python3 scripts/build_data.py --strict
 → git commit / push → 自動デプロイ
```

Claude Code では `/update-shops hakata-oldtown-pay` で、CSV の更新から差分確認までをまとめて実行できます（`.claude/commands/update-shops.md`）。

## 営業時間・店舗画像を入れる

`raw/hakata-oldtown-pay.csv` の列に書くだけです。書いた店だけに表示され、「営業中のみ」ボタンは、営業時間のある店が1軒でもあれば自動で出ます。

| 列 | 内容 | 例 |
|---|---|---|
| `hours` | 営業時間（下の書式） | `月-金 11:00-14:00,17:00-22:00; 土 11:00-22:00; 日 休` |
| `hours_note` | 補足（任意） | `L.O. 閉店30分前、祝日は休み` |
| `hours_checked` | **確認した日**（営業時間があるなら必須） | `2026-10-22` |
| `image` | 画像のファイル名（`public/img/shops/` に置く） | `okubo-saketen.jpg` |
| `image_credit` | **提供元・許諾の出所**（画像があるなら必須） | `大久保酒店 提供` |

- `hours` の書式: 曜日と時間を半角スペースで区切り、`;` で区切って並べる。曜日は `月-金`・`土`・`月・水・金`・`毎日`、定休日は `休`。深夜営業は `18:00-26:00`（翌2時まで）。書いていない曜日は「不明」として扱い、営業中の判定からは外れます。
- 判定は**日本時間**で行います（海外や端末の時刻設定が違っても、日本の営業時間として判定）。
- 書式や必須項目を間違えると `build_data.py` がエラーで止まります（`image_credit` が空、画像ファイルが無い、など）。
- 画像は 300KB 以下（横800px程度・JPEG）を推奨。`public/img/shops/` の中に自サイトの画像として置きます（他サイトの画像を直接リンクしません）。

### 営業時間の入力を楽にするツール

営業時間をご自身の目で確認して入力するときは、貼り付けるだけで書式に変換するツールが使えます（Googleマップの自動取得ではありません）。

```bash
python3 scripts/hours_helper.py --open      # 営業時間が未入力の店を1軒ずつ。--open で Googleマップを自分のブラウザに開く
```

1. 店名とGoogleマップのURLが表示されます（`--open` なら自動で開きます）
2. 営業時間の表（月曜日〜日曜日）をコピーして貼り付け → 7日ぶんそろうと自動で確定（曜日の間の空行、`18時00分～22時00分` 表記もOK。一部の曜日だけのときは空行を2回）
3. 変換結果（例: `月-金 11:00-14:00,17:00-22:00; 土 11:00-22:00; 日 休`）を確認して Enter で保存。補足（L.O. など）も入れられます
4. `s` でスキップ、`q` で終了（保存済みの分は残ります）。入力済みの店を直すなら `--redo`、1軒だけなら `--name 店名`

日本語表記（`月曜日 11:00～14:00, 17:00～22:00` / `18時00分～22時00分` / `定休日` / `24 時間営業`） と英語表記（`Monday 11:00 AM – 2:00 PM` / `Closed`）に対応しています。確認日は自動で今日の日付になります。
変換だけ試すときは `python3 scripts/hours_helper.py --text "月曜日 11:00～14:00 火曜日 定休日"` です。最後に `python3 scripts/build_data.py --strict` で検証してください。

### データの集め方（どれが安全か）

| 方法 | 評価 |
|---|---|
| **御供所名店会に、店舗の営業時間と写真の提供・掲載を依頼する** | ◎ いちばん確実。掲載確認の連絡と一緒に頼める |
| **各店のサイト・SNS・店頭、または自分の目で見たGoogleマップの表示を、手入力（上のツールで変換）**（`hours_checked` に確認日） | ○ 事実情報（営業時間）の手入力は現実的。変更に弱いので、画面にも確認日と注意書きを出しています |
| 各店に「掲載してよいか」を聞いて写真をもらう | ○ 件数が多いので、まずは主要な店から |
| 公式サイトの店舗写真（`hakata-oldtownpay.com/shoplist/upload/`）を使う | △ 著作権があるため、名店会の許諾が前提。許諾が取れたら自サイトにコピーして使う |
| Google マップの営業時間・写真を取得して保存・表示する | ✕ Google の規約で保存できず、毎回API呼び出し（有料枠あり）になる。やらない |
| OpenStreetMap の `opening_hours` | △ 無料で使えるが、登録のない店が多い（出典表示が必要） |

## 補足

- **地図タイル**: 既定は OpenStreetMap の公式タイルです。アクセスが増えると利用ポリシー上の問題になり得るため、`public/app.js` 冒頭の `TILE` を国土地理院タイル等に切り替えられます。
- **Leaflet は CDN（unpkg）から読み込み**ています。自前配信にしたい場合は、ローカルで `npm i leaflet@1.9.4 leaflet.markercluster@1.5.3` し、`dist/` の中身を `public/vendor/` にコピーして `index.html` の URL を書き換えてください。
- **カテゴリ**は公式の分類ではなく、このプロジェクトでの独自分類です（`scripts/common.py` の `CATEGORIES`）。
- 店舗の加盟開始日は店ごとに異なります。公式サイトも「利用準備が整っていない場合がある」と案内しているため、画面にも同じ注意を出しています。
